# Product Prototypes 2025

An archive of early interface and product experiments. These files are retained
as learning artifacts, not as a deployable application or production system.

## Included prototypes

| Area | What is present | Status |
| --- | --- | --- |
| Mobile dashboard | React Native progress and meal-detail screens | Partial UI prototype |
| Wallet | A small wallet page experiment | Partial UI prototype |
| Authentication | A Next.js login page | Partial UI prototype |
| Credential API | An early NestJS package manifest | Scaffold only |

## Repository status

- Generated Next.js output and operating-system metadata are intentionally not tracked.
- The prototypes do not share one runnable root workspace.
- No live service, production deployment, customer use, or security assurance is claimed.
